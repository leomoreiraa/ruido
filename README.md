# RUÍDO — site e código-fonte

Este repositório contém o site estático publicado em https://ruido.runs-at.dev/
e o código-fonte auditável do frontend e backend em [source/](source/).
Inclui React/Next.js, coletores, lógica das IAs e schema do banco.

A execução privada mantém o SQLite real, checkpoints, credenciais,
histórico operacional e configurações dos GitHub Actions fora do espelho.
O código em source/ não é executado diretamente pelo GitHub Pages.
