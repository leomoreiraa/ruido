# RUÍDO — publicação pública

Este repositório é um **espelho de publicação estática** do projeto RUÍDO. Os arquivos são gerados, auditados e publicados automaticamente pelo sistema privado.

Ele contém somente páginas, JavaScript/CSS do navegador, imagens e conjuntos de dados públicos validados. Não contém credenciais, scripts de coleta, checkpoints, GitHub Actions operacionais ou histórico Git do sistema de produção.

O repositório de publicação não recebe contribuições operacionais diretamente; modificações no site são realizadas no projeto principal.

Site: https://ruido.runs-at.dev/
