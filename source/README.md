# RUÍDO — código-fonte público

Esta pasta contém o código legível do frontend e do backend: páginas React/Next.js, componentes, rotas de API, serviços de coleta, integrações com IA, testes e o schema Prisma.

**Não inclui** arquivos SQLite, dados operacionais, checkpoints, secrets, variáveis de ambiente, histórico Git privado nem configurações de GitHub Actions. A execução acontece no repositório de produção privado; o código público é publicado automaticamente após auditoria.

O código-fonte NÃO é um backend em funcionamento no Pages: o site usa arquivos estáticos previamente gerados.

O manifest.json lista o hash SHA-256 de cada arquivo do snapshot para facilitar auditoria e comparação de versões.
